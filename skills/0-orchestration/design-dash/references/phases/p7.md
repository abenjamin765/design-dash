# P7 — Optional Build

Detailed source for this phase. See also the orchestrator summary in `SKILL.md`.

P7 is an **optional coded prototype**. The primary Design Dash deliverable remains the PLAN (wireframe, specs, pitch). When `prototype_workspace` is unset or no design-system base page is resolvable, run **stub mode** and continue to P8.

## Stub mode (default when no build target)

If no resolvable prototype base / `prototype_workspace`:
1. Write `dashes/{slug}/p7-build-note.md` stating blocked reason (or "stub by design"), intended filename, planned sections/surfaces, and instrumentation events from `metrics.md`.
2. Do **not** claim a prototype is built.
3. Continue to P8; pitch site Links tab points at `wireframe.html` + `p7-build-note.md`.
4. Announce: "P7 stub mode — coded prototype deferred (no prototype workspace / base page)."

**Never invent a proprietary design-system tree inside this repo.**

## Optional full build — dispatch as subagent (workspace + base resolvable)

### Subagent brief contract — Optional prototype build (P7)

**Main thread passes:**
- `slug`, `prototype_workspace` absolute path, resolvable base-page path (if any), `wireframe.html` absolute path, `metrics.md` absolute path, tier, hub object (name + slug), chosen concept name

**Subagent writes to disk:**
- Prototype HTML under `{prototype_workspace}/` at the path the workspace contract specifies
- Deviation notes at `dashes/{slug}/deviations/<Name>.md` (if any)
- Updates any local prototype index the workspace already uses (do not create a second tree)

**Subagent returns to main thread (cap 500 tokens):**
- Built path (or stub path + reason if build blocked mid-subagent)
- Deviation count
- Instrumentation events wired (Y/N)

**Subagent runs:**
7.1 Map wireframe sections to available components in the configured design system (or plain HTML if none).
7.2 Mock data grounded in object-library Identity/Attributes — not Lorem Ipsum.
7.3 Copy/adapt the base page into the prototype path; swap content; wire JS as needed for the demo.
7.4 FORK: any deviation or new component needed? → document in `dashes/{slug}/deviations/<Name>.md`. Workshop continues without blocking.
7.5 Accessibility verification on live HTML when a server can be started. Load `skills/7-critique-testing/a11y-audit/SKILL.md` for the structured pass when tier is Standard or High-stakes.
7.6 **Craft check**: run P7.D craft pillars in `references/critique-checklists.md` when present. Optional visual-quality pass against the built HTML.
7.7 **Preview gate** *(WAIT FOR USER — all session modes, including solo)*: serve the prototype when possible, give the designer the local URL, and wait for an explicit verdict (`approved` / `changes requested`) before closing P7. Record the verdict in the phase boundary notes (or `auto-confirms.md` only if the designer pre-authorized skip — default is wait).

**Instrumentation hooks**: before closing P7, wire the success-metric events from `metrics.md` into the prototype (or document them as planned production events if they cannot be prototyped). High-stakes: live instrumentation must be wired or explicitly debt-tracked before P8 can complete.

**Output**: prototype page and/or `dashes/{slug}/p7-build-note.md`; `living-plan/phases/p7.mdx`.
